# Portfolio

A minimal static portfolio website.

## Files
- [portfolio.html](portfolio.html) — single-page portfolio site (main file).

## View locally
- Open [portfolio.html](portfolio.html) directly in your browser (double-click).
- Or serve the folder with a simple HTTP server and open the page:

```
python -m http.server 8000
# then open http://localhost:8000/portfolio.html
```

## Edit
- Modify `portfolio.html` to update content, images, or styles.
